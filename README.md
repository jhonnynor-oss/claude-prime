# claude-prime

Mon espace de travail pour construire, tester et garder mes meilleurs usages de Claude.

## Pourquoi ce projet

Chaque bon prompt finit perdu dans une conversation. Ici, je le garde.
Un seul endroit pour mes prompts, mes modèles et mes projets.
Rangé, versionné, réutilisable.

## Ce que tu trouves ici

```
claude-prime/
├── prompts/       mes prompts testés et validés
├── modeles/       mes trames réutilisables (briefs, scripts, plannings)
├── projets/       un dossier par projet en cours
├── notes/         idées, essais, apprentissages
├── index.html     la page web du projet (GitHub Pages)
└── README.md      tu es ici
```

## Le site

La page `index.html` est publiée avec GitHub Pages.
Adresse : `https://jhonnynor-oss.github.io/claude-prime/`

Pour l'activer : **Settings**, puis **Pages**, source **Deploy from a branch**, branche **main**, dossier **/ (root)**, puis **Save**.

## Comment je l'utilise

1. **Je teste** un prompt dans Claude.
2. **Je garde** ce qui marche dans `prompts/`, avec un exemple de résultat.
3. **Je réutilise** au lieu de repartir de zéro.

## Règles du dépôt

* Un fichier par prompt, nommé clairement : `brief client.md`, `script reel.md`
* Chaque prompt indique : son objectif, le prompt complet, un exemple de résultat
* Rien de confidentiel ici : pas de mots de passe, pas de données clients
